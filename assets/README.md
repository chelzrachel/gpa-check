# School logo

To display the official School of Foundation Studies logo, upload a PNG image **named exactly `school-logo.png`** to this `assets` folder. This is a school-managed GitHub file, not a student upload.

The website shows `SFS` in the header and PDF if the file is not present. The official image will appear automatically when you add it. A transparent PNG with reasonable padding works best. No code changes are needed. Do not include student information or private files in this public repository.
